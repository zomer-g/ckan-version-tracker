המשימה

פתוח כברירת מחדל — ובאמת נשמר

מאגרים ממשלתיים משתנים ונמחקים בשקט. גרסאות לעם עוקב, מארכב ומנגיש — כדי שאף גרסה לא תיעלם, וכל שינוי יהיה ניתן לבדיקה.

  • שקיפות ברת‑אימות — כל נתון מקושר חזרה למקור הממשלתי המקורי.

  • נגישות לכולם — מאדם שמחפש קובץ ועד סוכן AI ששואל שאלה.

06
SQL / נתונים

שאילתות חופשיות על כל האתר

קונסולות SQL ציבוריות לקריאה בלבד, על תפקיד DB בעל הרשאות מינימום — עם השלמה אוטומטית, תיקון שגיאות והפניית סכימה ל‑AI.

/data מרכזי

SQL חוצה‑סכמות מעל כל טבלאות האתר, עם בונה‑תרשימים ללא‑קוד.

/knesset

48 טבלאות ODATA‑v4 של הכנסת ממורות ל‑Neon, עם עמודות מוקלדות.

לכל מאגר

קונסולת ארכיון לכל dataset מבוסס‑NEON, עם ייצוא CSV.

📊 תרשימים: עוגה / עמודות / קו / פיזור / מפה — עם ייצוא PNG/SVG ושיתוף בקישור.

07
מרחבי / מפות

מהטבלה אל המפה

שכבות GovMap

גירוד WFS מלא של מאות שכבות, כולל שכבות ענק בפורמט GPKG / GeoParquet.

מפה אינטראקטיבית

תצוגת מפה חיה בעמוד המאגר: פילטרים קטגוריאליים, מסך מלא, זרימת נתונים.

PostGIS

עמודת geom על שכבות ממורות — ST_* אמיתי, ניתוח מרחבי וחיתוכי פוליגונים.

ניתוח על מפה

תוצאות SQL מרחביות מצוירות על מפה, צבועות לפי קטגוריה, ישר בקונסולה.

12
מתחת למכסה

הארכיטקטורה

Worker חיצוני

govil‑scraper בתור משימות, מעדכן את עצמו בין ריצות, ריבוי‑מכונות.

אחסון R2

Cloudflare R2 כ‑backend עצמאי, עם העלאות presigned ישירות.

NEON Postgres

מסד append נפרד מהסודות, לטבלאות ניתנות‑לשאילתה.

מקורות דקלרטיביים

ה‑Worker מכריז על מקור חדש דרך manifest — בלי קוד ב‑OVER.

המסע: מ‑ODATA כאחסון בלעדי → ל‑R2+NEON; מהוספת מקור בשני repos → להכרזה דקלרטיבית אחת.

13
ניהול ותפעול

אדמין, תפעול ואבטחה

פאנל אדמין

תור גירוד, ניהול אחסון per‑dataset, ייצוא לדרייב, ועריכת טקסטים בזמן ריצה.

לוג פעילות

יומן lifecycle append‑only לכל אירוע מאגר/גירוד.

אבטחה

SQL על תפקיד read‑only במסד נפרד; בלי JWT ב‑URL; rate‑limit לכל endpoint.

שער גרסת Worker מונע מ‑worker מיושן לדחוף נתונים; שומרי memory מגנים על dyno של 512MB.
